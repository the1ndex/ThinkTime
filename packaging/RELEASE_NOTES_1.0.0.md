# ThinkTime 1.0.0

ThinkTime 的首个公开版本。下载 `ThinkTime-1.0.0-win-x64-portable.zip`，解压后直接运行 `ThinkTime.exe`；便携包已包含 .NET 运行时。

### 本版内容

- Windows 11 动态世界时钟壁纸，每 60 秒更新；
- 实时晨昏线、时区网格和 12 个城市当地时间；
- NASA Black Marble 夜间灯光遮罩；
- 北京、香港与中国行政边界覆盖层；
- 简体中文 / English 双语界面；
- 托盘控制、低功耗模式和 Per-Monitor V2 高 DPI 支持。

> 当前可执行文件没有商业代码签名证书，首次运行时 Windows SmartScreen 可能显示“未知发布者”。请核对下载来源与随附的 SHA-256 文件。

---

The first public release of ThinkTime. Download `ThinkTime-1.0.0-win-x64-portable.zip`, extract it, and run `ThinkTime.exe`; the portable package includes the .NET runtime.

### Included in this release

- Windows 11 live world clock wallpaper with a 60-second refresh cadence;
- live solar terminator, time-zone grid, and local time for 12 cities;
- NASA Black Marble night-light masking;
- Beijing, Hong Kong, and a dedicated China administrative-boundary layer;
- Simplified Chinese / English interface;
- tray controls, low-power mode, and Per-Monitor V2 DPI support.

> The executable is not signed with a commercial code-signing certificate. Windows SmartScreen may show an “Unknown publisher” warning on first launch. Verify the download source and the accompanying SHA-256 file.
